# Percentage Change Calculator: Increase, Decrease and Formula

A **Percentage Change Calculator** measures how much a value has increased or decreased relative to its original value.

## Percentage Change Formula

**Percentage Change = (New Value − Old Value) ÷ Old Value × 100**

A positive result means an increase; a negative result means a decrease.

For example, if a price changes from ₹800 to ₹1,000, the change is ₹200. Dividing ₹200 by ₹800 and multiplying by 100 gives a **25% increase**. If it changes from ₹1,000 to ₹800, the result is a **20% decrease**.

## How to Use the Calculator

1. Enter the original value.
2. Enter the new value.
3. Calculate the percentage change.
4. Check that the original value is not zero, because division by zero is undefined.

## Percentage Change vs Percentage Difference

Percentage change uses a specific starting value as the baseline. Percentage difference is often used to compare two values without designating one as the original and may use their average as the denominator. They answer different questions.

## Where It Helps

You can compare price changes, monthly expenses, sales, marks, business metrics, or other values measured consistently over time.

## Common Mistakes

- Using the new value as the denominator instead of the original value.
- Forgetting the sign of the result.
- Comparing values with different units or periods.
- Assuming a 20% decrease followed by a 20% increase returns to the original value; it does not.

Use percentage change to describe a past movement, not to predict what will happen next.

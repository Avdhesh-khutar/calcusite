# Calcusite

Calcusite is a modern, responsive online calculator built with HTML, CSS, JavaScript, Hono and Cloudflare Workers.

## Project structure

- `src/index.js` — Hono/Cloudflare Worker entry point
- `public/index.html` — website
- `public/style.css` — design and responsive layout
- `public/script.js` — calculator logic
- `wrangler.jsonc` — Cloudflare configuration

## Install

```bash
npm.cmd install
```

## Run locally

```bash
npm.cmd run dev
```

## Deploy

```bash
npm.cmd run deploy
```
